## Data Preparation Fine Tuning And Agents

### 1. 데이터 정제

메모는 "Data First" 관점을 강조한다.

- 시드 데이터에서 학습 데이터를 만든다
- 오픈데이터를 활용할 수 있다
- 영어 데이터를 한글로 번역해 활용할 수도 있다

즉, 모델 성능 이전에 데이터 준비가 먼저다.

### 2. 파인튜닝 범위

파인튜닝은 크게 두 방식으로 나눌 수 있다.

- **full fine-tuning**
  - 모델 전체를 학습한다
  - 자원 요구량이 크다

- **LoRA**
  - 일부 행렬 adapter만 추가 학습한다
  - 자원 효율이 훨씬 좋다

메모에서는 대형 모델일수록 LoRA의 현실성이 더 강조된다.

### 3. LoRA 핵심 감각

LoRA는 원래 모델 전체를 바꾸기보다 일부 보조 행렬을 붙여 학습한다.

그래서:

- 적은 자원으로도 실험 가능하고
- 목적에 맞는 빠른 적응이 가능하다

추가 메모:

- `target_module`은 보통 transformer layer의 `q`, `k`, `v`, `o`, `up`, `down`, `gate` 같은 부분을 가리킨다

### 4. 하이퍼파라미터

메모에서 언급한 대표 하이퍼파라미터는 다음과 같다.

- epoch
- LoRA rank
- alpha

이 값들은 모델이 무엇을 배우는지가 아니라, **어떻게 배우게 할지**를 정하는 설정이다.

### 5. 에이전트 관점

후반 메모는 에이전트를 아주 실용적으로 정리한다.

- 여러 도구가 주어진다
- 사용자의 질문을 파악한다
- 적절한 도구를 매칭한다
- 도구를 실행해 결과를 낸다

즉:

- **단순 LLM**
  - 그냥 대화하는 모델

- **에이전트**
  - 도구를 붙이고, 상황에 맞게 실행 흐름까지 다루는 시스템

이 관점은 최근 NLP가 단순 문장 처리에서 도구 사용형 AI 시스템으로 넓어졌다는 흐름과 연결된다.

### 6. 이 모듈 전체를 관통하는 실무 포인트

메모 두 파일을 합치면 흐름은 이렇다.

1. 언어모델과 Transformer 구조를 이해한다.
2. 검색과 임베딩, 리랭킹으로 RAG 품질을 높인다.
3. 평가 지표로 검색 성능을 객관화한다.
4. 데이터 정제와 LoRA로 실무형 파인튜닝을 한다.
5. 필요하면 에이전트 구조로 확장한다.

### 한 줄 정리

- Text Mining과 NLP 실무는 모델 자체보다도 데이터, 검색, 평가, 파인튜닝, 도구 연결을 함께 설계하는 문제에 가깝다.
