# aSSIST2026

## About This Program
이 저장소는 **aSSIST 서울과학종합대학원대학교(aSSIST University) AI·빅데이터 석사 과정** 학습 기록입니다.  
2026-1학기 전공심화 기준으로, AI 시스템 설계와 응용 중심의 모듈들을 이론과 실습을 함께 엮어 정리하고 있습니다.

- 과정: AI·빅데이터 석사
- 학교: aSSIST 서울과학종합대학원대학교 (aSSIST University)
- 학기 성격: 2026-1 전공심화
- 주요 학습 축: 강화학습, 시계열 분석, Transformer / LLM 구조, Ontology / Knowledge Graph, RDB·SQL·Text-to-SQL·RAG 실습, Text Mining & NLP, AI Project

## Repository Goal
이 Git의 목표는 다음 3가지를 한 곳에 체계적으로 남기는 것입니다.

1. 강의 필기와 개념 요약 정리
2. AI 활용 흔적(요약, 구조화, 비교표, 프로젝트 정리)
3. 실습 코드, 노트북, 프로젝트 산출물 기록

즉, 나중에 빠르게 복습하거나, 해당 과정을 궁금해하는 사람이 2026 학습 흐름 전체를 한 번에 파악할 수 있도록 만드는 학습 아카이브입니다.

## Writing Style
- 복습 친화형: 핵심 개념 위주로 짧고 구조적으로 정리
- 모듈 분리형: 주제별 폴더와 `00TableOfContents.md` 중심 구성
- 실습 연계형: 설명 + 노트 + 프로젝트/노트북 산출물을 함께 기록
- 업데이트형: 수업 진행에 맞춰 계속 다듬고 보완
