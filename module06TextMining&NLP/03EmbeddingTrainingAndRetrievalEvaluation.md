### 1. 포지티브 샘플과 네거티브 샘플

임베딩 학습은 어떤 쌍을 가깝게 둘지, 어떤 쌍을 멀게 둘지 정하는 문제다.

- **포지티브 샘플**
  - 의미적으로 관련 있는 문장 쌍

- **네거티브 샘플**
  - 의미적으로 관련이 없거나 약한 문장 쌍

핵심 감각은 이렇다.

- 관련 있는 것은 가깝게
- 관련 없는 것은 멀게

### 2. 임베딩 학습의 기본 원리

메모의 흐름은 대조학습 관점으로 정리된다.

1. 포지티브와 네거티브 샘플을 준비한다.
2. 포지티브 쌍은 가깝게, 네거티브 쌍은 멀게 학습한다.
3. 보통 코사인 유사도 기반으로 손실을 최적화한다.

즉, 임베딩 학습은 "벡터 공간의 거리 배치"를 다루는 문제다.

### 3. Multiple Negatives Ranking Loss

메모에서 특히 강조한 포인트는 명시적 네거티브를 따로 만들지 않아도 되는 방식이다.

- **MultipleNegativesRankingLoss**
  - 배치 안의 다른 샘플들을 자동으로 네거티브로 활용한다

장점:

- 네거티브 샘플을 따로 준비하는 부담이 줄어든다
- 학습 효율이 좋아진다

추가 메모:

- 다중 네거티브가 트리플렛 방식보다 성능이 좋다고 정리되어 있다

### 4. 검색 평가 지표

검색 평가는 "정답이 들어왔는가"와 "얼마나 위에 떴는가"를 함께 봐야 한다.

메모에서 다룬 대표 지표는 다음과 같다.

- **Accuracy**
  - 상위 `k`개 안에 정답이 하나라도 포함되는가

- **Precision**
  - 상위 `k`개 결과 중 정답 비율이 얼마나 되는가

- **Recall**
  - 전체 정답 중 얼마나 많이 찾아왔는가

- **NDCG**
  - 정답이 높은 순위에 있을수록 더 높은 점수를 준다

- **MRR**
  - 첫 정답이 얼마나 빨리 등장하는가를 본다

- **MAP**
  - 여러 정답을 찾는 과정의 정확도를 평균적으로 본다

### 5. 지표별 해석 감각

각 지표는 보는 관점이 다르다.

| 지표 | 핵심 질문 |
| --- | --- |
| Accuracy | 정답이 들어오기만 했는가 |
| Precision | 쓸모 없는 결과가 적은가 |
| Recall | 정답을 놓치지 않았는가 |
| NDCG | 정답이 위쪽에 잘 배치됐는가 |
| MRR | 첫 정답을 빨리 찾을 수 있는가 |
| MAP | 여러 정답을 전반적으로 정확히 찾는가 |

실무에서는 보통 하나만 보지 않고 같이 본다.

- Recall만 높으면 잡음이 많을 수 있고
- Precision만 높으면 필요한 정답을 놓칠 수 있기 때문이다

### 한 줄 정리

- 임베딩 학습은 관련성 거리를 배우는 과정이고, 검색 평가는 정답 포함 여부와 순위 품질을 함께 봐야 한다.
